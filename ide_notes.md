# Git в VS Code и в терминале

## Удобно в VS Code
1. Разрешать конфликты: VS Code показывает кнопки Accept Current / Accept Incoming / Accept Both прямо над маркерами.
2. Diff в два столбца: видно старую и новую версию файла, можно откатить отдельный фрагмент.
3. Индикаторы на полях редактора (зелёный/синий/красный) сразу показывают добавленные, изменённые и удалённые строки.

## Удобнее в терминале
1. Работа с удалёнными репозиториями: git remote, push в несколько remote, fetch --all —
   в терминале это одна команда, а в IDE часть этих настроек вообще недоступна.
