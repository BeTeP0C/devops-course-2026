# Мои цели на семестр

1. Перевести свои учебные проекты на работу через ветки и Pull Request, без прямых коммитов в main.
2. Собрать docker-compose для фронтенда и бэкенда своего проекта и поднять его одной командой.
3. Настроить в GitHub Actions сборку и автоматический деплой на сервер после merge в main.
