# Мой пет-проект

Идея: веб-приложение «Расписание группы» — показывает пары на сегодня и неделю,
присылает уведомление в Telegram о переносе или отмене занятия.

Стек: TypeScript, React (фронтенд), Node.js + Express (бэкенд), PostgreSQL, Docker.

Цель: научиться выкатывать своё приложение на сервер — docker-compose,
Nginx как reverse proxy и автоматический деплой через GitHub Actions.
